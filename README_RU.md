# Управление подсветкой CIY X79 RGB для macOS и документация протокола

## 1. Обзор и быстрый старт

* **Модель:** Механическая клавиатура CIY X79 (формат 65%, Hot-Swap)
* **Микроконтроллер:** Sinowealth MCU (USB-контроллер на архитектуре 8051)
* **Идентификаторы USB:**
  * **Vendor ID (VID):** `0x258A` (Sino Wealth)
  * **Product ID (PID):** `0x0049`
  * **USB-интерфейс:** Interface `1` (Vendor-Defined HID Class)

### Совместимость раскладок (ISO-DE и ANSI-US)
Графический холст оптимизирован под раскладку **ISO-DE (68 клавиш)** с двухэтажным Enter и клавишей `< > |`.  
Международная версия **ANSI-US** имеет 67 клавиш (одноэтажный Enter). Низкоуровневый протокол USB-HID и адресация памяти абсолютно идентичны — все команды консоли и профили работают на ANSI-клавиатурах без ограничений.

### Быстрый запуск:
* **Графическое приложение (GUI):**
  Запустите `CIYX79Control.app`. Доступен интерактивный выбор цветов для любой клавиши, палитра macOS, пресеты (WASD, Стрелки, Cyberpunk, Полностью красный), импорт/экспорт JSON-профилей, **иконка в строке меню (Tray / Menu Bar Extra)** для быстрого переключения профилей при закрытом окне (с автоматическим разворачиванием свернутого окна `deminiaturize`), **автоматическое переключение профилей при запуске игр и приложений (Auto-Trigger с защитой от дребезга 250 мс)** без необходимости в правах Accessibility, автоматическое устранение конфликтов привязок приложений и безопасное освобождение системных IOKit-портов при выходе.
* **Консольная утилита (`ciy_ctl`):**
  ```bash
  # Проверить статус подключения
  ./ciy_ctl status
  ./ciy_ctl status --json

  # Залить всю клавиатуру статичным цветом (Hex)
  ./ciy_ctl fill "#FF5500" 5

  # Игровые пресеты
  ./ciy_ctl wasd
  ./ciy_ctl wasd-arrows
  ./ciy_ctl all-red

  # Загрузить JSON-профиль (синтаксис: ./ciy_ctl load <profile.json> [имя_профиля] [яркость 0..5])
  ./ciy_ctl load profile.json
  ./ciy_ctl load profile.json "WASD" 5 --json
  ```

## 2. Установка и macOS Gatekeeper (первый запуск)

Поскольку проект является свободным Open-Source без платного сертификата Apple Developer, служба безопасности **Gatekeeper** при первом запуске может заблокировать приложение (*«Не удается проверить разработчика»*).

### Как открыть приложение:
* **Способ 1 (Через Finder — рекомендуется):**
  1. Переместите `CIYX79Control.app` в папку `/Applications` («Программы»).
  2. Нажмите правой кнопкой мыши (или `Control` + клик) на `CIYX79Control.app` и выберите **«Открыть»**.
  3. В появившемся диалоговом окне нажмите **«Открыть»** («Все равно открыть»).
* **Способ 2 (Через Терминал):**
  ```bash
  xattr -cr /Applications/CIYX79Control.app
  ```

## 3. Ключевые особенности протокола и реверс-инжиниринга

В целях обеспечения функциональной совместимости с macOS (в соответствии со ст. 69e Закона об авторском праве Германии UrhG и ст. 3 Закона о коммерческой тайне GeschGehG) был изучен протокол USB-HID клавиатуры:

1. **Режим 19 (`0x13`) — Customize:** Только в режиме 19 микроконтроллер считывает цвета отдельных клавиш из встроенной памяти XRAM. Режим 20 — это стандартная радужная волна.
2. **Обязательная последовательность пакетов:**
   * Отправка **`Report 0x0B` (379 байт)**: Запись планарных плоскостей RGB в XRAM.
   * Пауза **50 мс** (`usleep(50000)`): Микроконтроллер фиксирует буфер в памяти.
   * Отправка **`Report 0x0A` (42 байта)** с режимом 19: Мгновенное включение кастомного профиля без мерцания.
3. **Смещение индекса на +1:** Клавиша Esc (слот 1) в прошивке проецируется на адрес 0. Все физические индексы светодиодов смещены на **+1** ($\text{Индекс} = \text{Слот} + 1$).
4. **Энергозависимая память XRAM:** Цвета клавиш хранятся в оперативной памяти контроллера. При переключении эффектов сочетанием `Fn + ;` память перезаписывается прошивкой, но восстанавливается через утилиту за 50 мс.

## 4. Спецификация протокола USB-HID

Управление осуществляется через **USB Control Transfers** на Endpoint 0 (Interface 1):
* **Report 0x0A (42 байта):** Глобальные параметры (режим 0..20, палитра 0..10, скорость 0..4, яркость 0..5).
* **Report 0x0B (379 байт):** Планарная матрица RGB (3 плоскости по 126 байт: красный, зеленый, синий).

### Режимы работы (0 .. 20):
* `0`: Выключено
* `1`: Волна (Wave)
* `2`: Дыхание (Breathing)
* `3`: Всплеск (Ripple)
* `15`: Статичный сплошной цвет (Solid)
* `19`: **Поклавишный Custom RGB из XRAM**
* `20`: Радужная волна

## 5. Безопасность и конфиденциальность

* **Без кейлоггеров и перехвата ввода:** Приложению **не требуются** разрешения Универсального доступа (*Accessibility*) или Мониторинга ввода (*Input Monitoring*).
* **User Space (без kext):** Работа исключительно через официальный пользовательский API Apple `IOKit`.
* **100% Офлайн:** Отсутствуют сетевые сокеты, телеметрия и сторонние трекеры.
* **0.0% нагрузки на процессор:** В фоновом режиме утилита не производит опросов и не потребляет ресурсы CPU.
